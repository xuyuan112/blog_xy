## 修复 runtimeConfig.ts 在 tsx/纯 Node 下崩溃（构建后脚本报错）

- 症状：本地/服务器 `npm run build` 在 astro build 成功后、prune-pio-assets 阶段崩 `TypeError: Cannot read properties of undefined (reading 'PUBLIC_API_BASE_URL')`。
- 根因：runtimeConfig.ts 顶层直接用 `import.meta.env.X`，而 `import.meta.env` 只有 Vite 注入；tsx 跑的构建后脚本（经 src/config/index.ts → musicConfig → runtimeConfig 链条加载）里它是 undefined。
- 修复：3 处改为可选链 `import.meta.env?.X`（Vite 静态替换不受影响）。已用 `npx tsx` 验证加载正常，回退 localhost 默认值正确。
- 注意：我这边的沙箱有批量删除保护（>50 文件需确认），prune-pio-assets 删 dist/client/pio 被拦——用户自己终端和服务器上无此限制，可正常跑完。
- 部署包已重打（blog-app-ui-deploy-20260909.zip 含修复后的 runtimeConfig.ts）。
