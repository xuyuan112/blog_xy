检查结果如下。后端接口覆盖率较高，但前端页面和部分核心业务仍未完成，当前还不能认为展示系统已
  经闭环。                                                                                    
                                                                                              
  高优先级缺陷                                                                                
                                                                                              
  1. 文章详情页面缺失                                                                         
      - 后端已有 GET /xuyuan/articles/{id}。                                                  
      - 前端没有 ArticleDetailView.vue，路由 /articles/:id 不存在。                           
      - 首页文章卡片没有跳转逻辑，点击文章无法进入详情。                                      
      - 因此 Markdown、TOC、代码复制、上一篇/下一篇、文章评论和点赞都无法使用。               
      - 相关文件：blog-web-ui/src/views/home/HomeView.vue、blog-web-ui/src/router/index.ts    
      
  2. 首页功能未完成                                                                           
      - 首页只请求文章列表和热门文章。                                                        
      - 缺少公告、一言、天气、日程接口调用。                                                  
      - 没有分页或无限加载。                                                                  
      - 热门文章不可点击。                                                                    
      - 主内容接口失败时没有独立错误态和重试。                                                
      - 相关文件：blog-web-ui/src/views/home/HomeView.vue                                     
      
  3. 文章/杂谈正文未真正渲染 Markdown                                                         
      - 杂谈详情使用 <pre> 直接显示原文。                                                     
      - 缺少 Markdown HTML 渲染、代码高亮、代码复制、图片预览和 TOC。                         
      - 杂谈详情缺少评论组件。                                                                
      - 相关文件：blog-web-ui/src/views/thought/ThoughtView.vue                               
      
  4. 相册 EXIF 功能未完成                                                                     
      - 后端已有 GET /xuyuan/photos/{id}。                                                    
      - 前端定义了 getPhotoDetail，但没有调用。                                               
      - Lightbox 没有 EXIF 面板，也没有移动端底部抽屉。                                       
      - 没有真正实现焦点陷阱，键盘监听也没有在卸载时移除。                                    
      - 相关文件：blog-web-ui/src/views/gallery/GalleryView.vue                               
      
  5. 归档页面只有静态展示，缺少联动                                                           
      - 分类、标签、时间线没有跳转到文章列表。                                                
      - 没有携带 categoryId/tagId 查询参数。                                                  
      - 没有加载态、错误态和重试。                                                            
      - 页面中仍有大量编码异常文本。                                                          
      - 相关文件：blog-web-ui/src/views/archive/ArchiveView.vue                               
                                                                                              

  中优先级缺陷                                                                                
                                                                                              
  6. 点赞计数存在数据不一致风险                                                               
      - blog-parent/blog-web/blog-web-app/src/main/java/com/xuyuan/blog/web/service/like/impl/        LikeServiceImpl.java 返回的是 t_like 实时数量。                                       
        
      - 文章/说说列表读取的是实体中的 likeCount 字段。                                        
      - 点赞后没有同步更新 t_article.like_count 或 t_moment.like_count，列表数量可能长期不一  
        致。                                                                                  
        
      - 任务文档要求的 Redis 限流也尚未实现。                                                 
      
  7. Token 黑名单没有完整生效                                                                 
      - 登出时会写入 Redis 黑名单。                                                           
      - blog-parent/blog-web/blog-web-app/src/main/java/com/xuyuan/blog/web/custom/security/  
        AppJwtAuthenticationFilter.java 只解析 JWT，没有检查黑名单。                          
        
      - 已登出的 accessToken 仍可能访问受保护接口。                                           
      - RefreshToken 刷新时也没有检查黑名单。                                                 
      
  8. 前端没有实现单飞刷新 Token                                                               
      - blog-web-ui/src/utils/request.ts 遇到 601 会直接清空用户状态。                        
      - 没有调用 refresh 接口，也没有并发请求队列。                                           
      - 与任务文档要求的“单飞刷新 Token”不一致。                                              
      
  9. 评论只接入了说说详情                                                                     
      - CommentSection 已接入说说。                                                           
      - 由于文章详情页不存在，文章评论当前无法使用。                                          
      - 未登录评论处理已与当前 JWT 策略一致。                                                 
      
  10. 没有 NotFound 页面                                                                      
      - 路由没有 * / 404 页面。                                                               
      - 非法文章、相册、说说 ID 目前多为跳回列表或空白状态。                                  
      - 与任务文档要求不一致。                                                                
      
  11. 部分公共组件尚未实际使用                                                                
      - AsyncState.vue、BaseCard.vue、ResponsiveImage.vue 已存在，但多数页面仍使用重复的 v-   
        loading、el-empty 和原生图片逻辑。                                                    
        
      - 尚未建立 usePagination、useLightbox、useCountdown、useMediaQuery 等 composable。
